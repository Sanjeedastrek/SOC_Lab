a. Create Sentinel Workspace in Azure portal

Jun 25, 20261 min read

You have to have a subscription before creating a workspace.
Create Log Analytics Workspace where mention resource group, region, instance name etc.
This Log Analytics workspace is where all the logs (from the VM) will be stored and where Sentinel will search them. Microsoft Sentinel is fully cloud-native. There is no on-premise version of Sentinel unlike Splunk Enterprise.
