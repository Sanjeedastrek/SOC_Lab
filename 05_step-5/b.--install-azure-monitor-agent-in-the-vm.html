b. Install Azure Monitor Agent in the VM

b. Install Azure Monitor Agent in the VM

Jun 25, 20262 min read

The recommended way to install the Azure Monitor Agent through the Azure portal is to create a data collection rule (DCR). The Azure Monitor Agent is installed automatically if necessary, and an association is created between the DCR and each machine you select. But, there’s a catch. Since my target machine resides in-premise outside of Azure, I’ve to install Arc in my target machine. So, let’s create ARC & then create DCR

i. Create Azure Arc on the target

Open Arc in the search bar, then search for machines at the left, then create it. Also you need to click, ‘download & run script’ to download the script, which you need to run in your powershell admin cli. Azure Arc connects your on-premises or personal VM to Azure, installs the Azure Monitor Agent, and enables cloud management through the Azure portal. However, the agent alone doesn’t know what to collect. You must create a Data Collection Rule that specifies which logs to gather, from which machines, and where to send them, which is in my case, Sysmon logs to Sentinel workspace. Without the DCR, the agent sits idle.
