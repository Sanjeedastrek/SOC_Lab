
Download the Windows 11 Pro ISO and install it on VirtualBox (or any other hypervisor).

1. Downloaded Windows 11 ISO (Pro).

2. Then select New in VirtualBox, and show the ISO location. Then go to Settings, increase RAM & processor quantity, then start the machine.

3. You'll see that when it starts itself, you can't do anything like clicking the file menu or accessing the OS, which means installation is not yet done completely. It takes multiple restarts of the OS to install properly. You need to power off the VM manually & then start it manually repeatedly.

4. Continue part 3 until you see a step is repeating itself. If it happens, it means that your system is ready to use. In my case, when I twice saw the option to use a personal account or work/school account, I knew my basic installation was over. You don't need to change boot order.
